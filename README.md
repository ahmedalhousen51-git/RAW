# RAW — مطبخ الكافيه ثلاثي الأبعاد

تجربة ويب تفاعلية بتفتح على مطبخ كافيه RAW من منظور أمامي واسع: أرضية خشب،
بلاط بيج على الجدار الخلفي، خزائن زمردية بمقابض نحاس، جزيرة وسطية، سبع محطات
تحضير، وباريستا بيتمشى في المكان. كل حاجة مبنية بـ **three.js** من غير أي
موديلات أو تكستشرات خارجية — الخامات كلها مرسومة على canvas وقت التشغيل.

## التشغيل

من فولدر المشروع:

```bash
python3 -m http.server 8000
```

وبعدين افتح `http://localhost:8000/index.html`.

الصفحة كمان بتشتغل بالدبل-كليك من الفايندر: نسخة three المحلية في `vendor/`
بتتمنع على `file://` بسبب الـCORS، فالكود بيرجع تلقائي لنسخة CDN.

## التحكّم

| الحركة | إزاي |
| --- | --- |
| المشي | الأسهم أو `WASD` |
| تروح لنقطة | دوس على الأرض |
| تفتح محطة | دوس على الماكينة، أو زرارها من لوحة المخزون، أو `E` وانت واقف عندها |
| تقفل لوحة العمل | زرار ✕ أو `Esc` أو ابعد عن المحطة |
| تدوير الكاميرا | اسحب بالماوس (محدود يمين وشمال) |
| تقريب وتبعيد | عجلة الماوس |

روابط مباشرة: `?go=espresso` يمشيه للمحطة · `?at=espresso` يبدأ عندها.

## المحطات

`espresso` · `grinder` · `syrup` · `milk` · `ice` · `tea` · `brew`

كل محطة ليها تعريف موحّد: `{ id, label, obj, at, view, lamp, plume }` —
`at` نقطة الوقوف على الأرض، و`view` إزاحة الكاميرا في اللقطة القريبة.

## الواجهة البرمجية

المشهد بيتعرّض على `window.RAWKitchen`:

```js
RAWKitchen.goTo('espresso')   // يمشي للمحطة وتتفتح لوحتها لما يوصل
RAWKitchen.place('espresso')  // ينقله فوراً من غير مشي
RAWKitchen.teleport(0.2, 2.3) // ينقله لأي نقطة على الأرض
RAWKitchen.use('grinder')     // يشغّل ماكينة
RAWKitchen.at()               // المحطة اللي هو واقف عندها أو null
RAWKitchen.where()            // { x, z }
RAWKitchen.goalAt()           // الهدف اللي ماشي ناحيته أو null
RAWKitchen.stats()            // draw calls ومثلثات وجيومتري وتكستشرات
RAWKitchen.destroy()          // بيوقف الحلقة وينضّف الـlisteners والذاكرة
```

## ملاحظات على الأداء

- ظل واحد بس بيتحسب (الـkey light)؛ باقي الأضواء من غير ظلال.
- الخامات متكاشة ومتشاركة، والتكستشرات مرسومة مرة واحدة ومكرّرة.
- مفيش postprocessing — الـtone mapping بيقوم بالمطلوب من غير bloom يغسل التفاصيل.
- `destroy()` بيلغي الـrequestAnimationFrame وبيشيل كل الـevent listeners
  وبيعمل dispose للجيومتري والخامات، فمفيش حلقتين شغالين لو الصفحة اترّكبت تاني.
