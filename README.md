# RAW — مطبخ الكافيه ثلاثي الأبعاد

تجربة ويب تفاعلية بتفتح على مطبخ كافيه RAW من منظور أمامي واسع: أرضية خشب،
بلاط بيج على الجدار الخلفي، خزائن زمردية بمقابض نحاس، جزيرة وسطية، سبع محطات
تحضير، وباريستا بيتمشى في المكان. كل حاجة مبنية بـ **three.js** من غير أي
موديلات أو تكستشرات خارجية — الخامات كلها مرسومة على canvas وقت التشغيل.

## التشغيل

من فولدر المشروع:

```bash
python3 -m http.server 8000
```

وبعدين افتح `http://localhost:8000/index.html`.

الصفحة كمان بتشتغل بالدبل-كليك من الفايندر: نسخة three المحلية في `vendor/`
بتتمنع على `file://` بسبب الـCORS، فالكود بيرجع تلقائي لنسخة CDN.

## التحكّم

| الحركة | إزاي |
| --- | --- |
| المشي | الأسهم أو `WASD` |
| تروح لنقطة | دوس على الأرض |
| تفتح محطة | دوس على الماكينة، أو زرارها من لوحة المخزون، أو `E` وانت واقف عندها |
| تقفل لوحة العمل | زرار ✕ أو `Esc` أو ابعد عن المحطة |
| تدوير الكاميرا | اسحب بالماوس (محدود يمين وشمال) |
| تقريب وتبعيد | عجلة الماوس |

روابط مباشرة: `?go=espresso` يمشيه للمحطة · `?at=espresso` يبدأ عندها.

## الواقعية: إيه اللي بيتحرك في المشهد

**فيزياء السائل (`raw-drink.js`)** — كوباية زجاج على الجزيرة بتروح مع نورة لأي محطة
تفتحها. سطح السائل بيتموّج بموجتين بتخمدوا، والسائل بيتخبط في الجناب (سلوشينج)
لما الكوباية تتحرك، وفقاقيع بتطلع من القاع، وتيار حمل حراري بيلف السائل طول ما
هو سخن. اللون بيتمزج بالتدريج مع كل إضافة.

**الحرارة والوقت** — المشروب بيبرد لحرارة الأوضة (ثابت زمني ~٩٥ ثانية، و~٢٦
لو فيه تلج)، البخار بيقل مع البرودة، مكعبات التلج بتصغر وتدوب فترفع المستوى
وتبرّد أكتر، والكوباية الباردة بيتكثّف عليها ندى.

**الصوت (`raw-sfx.js`)** — صوت الصبّ نغمته بتعلى كل ما الكوباية تملى (عمود الهوا
بيقصر)، رنة تلج، صوت تقليب، وهمهمة خلفية للمكيّف والماكينات. كله مركّب بـWebAudio،
مفيش ملف صوت واحد خارجي.

**نورة (`raw-character.js`)** — راسها وعينيها بيتابعوا الماوس بزاوية محدودة زي
الرقبة الحقيقية، بترمش كل ٣-٧ ثواني، بتتنفّس وهي واقفة، بتبتسم أوسع لما الخطوة
تظبط وتتعجّب لما تغلط، ولما تبعد الماوس بترجع تبص على المحطة اللي قدامها.

**الجو (`raw-atmos.js`)** — غبار عايم بيتحرك في الضوء ومتكتّل ناحية النافذة،
عمود نور من النافذة، وانعكاسات حقيقية: كاميرا مكعّبة بترسم الأوضة كل كام ثانية
وبتتحط كـ`scene.environment`، فالستانلس والزجاج يعكسوا المكان بجد.

**الإضاءة حسب الوقت** — أربع حالات (الصبح · الضهر · المغرب · الليل) بتغيّر لون
وشدة كل الأضواء وخلفية المشهد. بتبدأ حسب ساعة الجهاز، وزرار في لوحة المخزون
بيلفّ بينهم.

## المحطات

`espresso` · `grinder` · `syrup` · `milk` · `ice` · `tea` · `brew`

كل محطة ليها تعريف موحّد: `{ id, label, obj, at, view, lamp, plume }` —
`at` نقطة الوقوف على الأرض، و`view` إزاحة الكاميرا في اللقطة القريبة.

## الواجهة البرمجية

المشهد بيتعرّض على `window.RAWKitchen`:

```js
RAWKitchen.goTo('espresso')   // يمشي للمحطة وتتفتح لوحتها لما يوصل
RAWKitchen.place('espresso')  // ينقله فوراً من غير مشي
RAWKitchen.teleport(0.2, 2.3) // ينقله لأي نقطة على الأرض
RAWKitchen.use('grinder')     // يشغّل ماكينة
RAWKitchen.at()               // المحطة اللي هو واقف عندها أو null
RAWKitchen.where()            // { x, z }
RAWKitchen.goalAt()           // الهدف اللي ماشي ناحيته أو null
RAWKitchen.serve(id, step, v) // أثر خطوة على المشروب (صبّ/تلج/تسخين/تقليب)
RAWKitchen.cupTo('espresso')  // ينقل الكوباية لمحطة، أو null ترجّعها للجزيرة
RAWKitchen.drink()            // { level, temp, ice }
RAWKitchen.newCup()           // كوباية فاضية جديدة
RAWKitchen.express('happy')   // تعبير مؤقت لنورة: 'happy' أو 'oops'
RAWKitchen.setTime('sunset')  // 'morning' · 'noon' · 'sunset' · 'night'
RAWKitchen.nextTime()         // يلفّ للحالة اللي بعدها
RAWKitchen.stats()            // draw calls ومثلثات وجيومتري وتكستشرات
RAWKitchen.destroy()          // بيوقف الحلقة وينضّف الـlisteners والذاكرة
```

## ملاحظات على الأداء

- ظل واحد بس بيتحسب (الـkey light)؛ باقي الأضواء من غير ظلال.
- الخامات متكاشة ومتشاركة، والتكستشرات مرسومة مرة واحدة ومكرّرة.
- مفيش postprocessing — الـtone mapping بيقوم بالمطلوب من غير bloom يغسل التفاصيل.
- انعكاسات البيئة بتتجدّد كل ٨ ثواني على ٩٦ بكسل بس، عشان الـ٦ رندرات ما تعملش تهتيت.
- كل اللي جوّه الكوباية (سائل، تلج، فقاقيع) من غير `transmission` — الزجاج لوحده
  هو الـtransmissive، وإلا three بتستبعدهم من خلفية الزجاج فيختفوا من جوّه.
- `destroy()` بيلغي الـrequestAnimationFrame وبيشيل كل الـevent listeners
  وبيعمل dispose للجيومتري والخامات، فمفيش حلقتين شغالين لو الصفحة اترّكبت تاني.
